# ☕🌿 Descubra o Norte do Paraná — Guia Turístico 

Aplicação web responsiva e interativa dedicada ao turismo no **Norte do Paraná** (Londrina, Maringá, Apucarana, Cornélio Procópio, Rolândia e Rota do Café), com comparador de preços de atrações, hotéis e restaurantes.

## ✨ Funcionalidades
- **Busca Inteligente & Filtros:** Filtro simultâneo por cidade, categoria, faixa de preço (`$`, `$$`, `$$$`) e pesquisa por texto em tempo real.
- **Comparador Lado a Lado:** Tabela comparativa de custo-benefício entre opções de hospedagem e gastronomia.
- **Modal Detalhado com Integração Local:** Tabela de preços de ingressos (inteira, meia, infantil), horários, dicas e sugestões de hotéis e restaurantes próximos a cada atração.
- **Calculadora de Orçamento & Roteiro:** Gaveta lateral interativa que soma passeios, diárias de hotel e refeições de acordo com o número de viajantes e dias, com exportação formatada para WhatsApp.

## 🚀 Tecnologias Utilizadas
- HTML5 Semântico
- Tailwind CSS (via CDN)
- JavaScript Vanilla (ES6+) + `localStorage` para salvar o roteiro
- Lucide Icons

## 📦 Como executar
Basta abrir o arquivo `index.html` em qualquer navegador ou ativar o **GitHub Pages** nas configurações deste repositório.
